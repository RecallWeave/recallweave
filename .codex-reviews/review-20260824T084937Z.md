```text

```


This contradicts the claim at [test_contract_markdown_injection.py](/Users/josh/particle-workers/recallweave/tests/test_contract_markdown_injection.py:1451) that every vault-note fixture written by the suite is checked. The current regression covers exactly `!s` and `:d`, not the general property.

### Medium — Reversed insertion test does not prove independence from implicit SQLite row order

[tests/test_contract_exclusions.py](/Users/josh/particle-workers/recallweave/tests/test_contract_exclusions.py:525) claims to make physical row order diverge, but reinserts rows with identical explicit `INTEGER PRIMARY KEY` values in both databases. SQLite stores/scans that table by rowid, so both unordered scans produce `KeepA, Drop, KeepB` despite reversed insertion:

```text
reverse=False unordered=[('KeepA',), ('Drop',), ('KeepB',)]
reverse=True  unordered=[('KeepA',), ('Drop',), ('KeepB',)]
```

Therefore the regression can continue passing if the production `ORDER BY` is accidentally removed. It verifies byte equality, but its setup does not perturb the implicit order it intends to guard against.
