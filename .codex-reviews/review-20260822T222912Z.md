## 1. Findings

### High — authored-link re-derivation still accepts fabricated verified relationships

[src/recallweave/contract.py](/Users/josh/particle-workers/recallweave/src/recallweave/contract.py:343) does not actually re-derive an authored link. `_authored_link_is_rederivable` independently checks that:

- `source_text` is any substring of a section covering the claimed line; and
- `target_text` resolves to the target note.

It never establishes that `source_text` contains a link, that the link targets `target_text`, or that its syntax matches `row["kind"]`.

I reproduced the bypass using an in-memory SQLite database, without modifying the tree. The source section was:

```text
This line contains no link at all.
```

The forged edge used:

```json
{
  "kind": "wikilink",
  "is_verified": 1,
  "score": 1.0,
  "evidence": {
    "line": 7,
    "source_text": "contains no link",
    "target_text": "Target"
  }
}
```

Output:

```text
authored_link_is_rederivable = True
edge_envelope_is_authentic = True
```

A hand-written row can therefore still export as an `authored_link`, `verified: true` relationship between unlinked notes. This is an evidence-integrity violation and leaves cycle 21’s High finding unresolved.

There are two additional weaknesses in the same routine:

- Name resolution accepts a matching `note_names` row without checking that the normalized name resolves uniquely. The real indexer rejects ambiguous names in [index.py](/Users/josh/particle-workers/recallweave/src/recallweave/index.py:267).
- Path resolution uses suffix matching such as `target_path.endswith(f"/{stripped}.md")`. That is broader than `_resolve_link`, which checks only exact vault-relative and source-relative normalized paths.

The documentation consequently overstates the implementation at [docs/task-contracts.md](/Users/josh/particle-workers/recallweave/docs/task-contracts.md:552), and the changelog’s claim that a hand-written verified relationship can no longer export is false at [CHANGELOG.md](/Users/josh/particle-workers/recallweave/CHANGELOG.md:17).

The decision not to recompute candidate existence and ranking is defensible if the artifact describes such rows as persisted, candidate-shaped records. The disclosure at [docs/task-contracts.md](/Users/josh/particle-workers/recallweave/docs/task-contracts.md:565) is materially honest.
